# Atlas Go 校园导航（Android 预览版）

Atlas Go 是 Campus Atlas 的安卓优先导航原型。它把当前 FF-01 教室轮廓接入手机端，提供二维校园图、路线预演、360° 视频方向标注和语音播报。

## 当前版本

- 版本：`0.2.0`
- 应用 ID：`top.georgehan0514.campusnav`
- 支持：Android 7.0（API 24）及以上
- 输出：`app-debug.apk`，用于现场试装和功能验证，不是 Play 商店签名包

## 安装

1. 在安卓手机允许“安装未知来源应用”。
2. 下载发布页中的 `atlas-go-0.2.0-android-debug.apk`，打开并安装。与原预览版使用相同应用 ID，可在签名相同时覆盖安装，保留本机资料。
3. 首次使用语音导航时，确认系统已安装中文 Text-to-Speech 语音数据。

这版不要求连接 Campus Atlas 网站才能打开地图；地图轮廓随 App 打包。实时校园数据、设备在线状态和室内定位还没有接入移动端。

## 使用方式

### v0.2.0 的使用体验

- 底部四个入口：探索、路线、全景导航、我的。首页增加常用空间与全景入口；“我的校园”集中展示收藏、现场路线和最近 20 条引导记录。
- 地图拖动有衰减惯性，双指缩放以手指中点为锚；选中房间和规划路线时自动避让顶部搜索栏和底部面板。标签按缩放等级显示，比例尺仍明确标注图纸单位。
- 路线新增估算步行时间、路线总览和完成页。查看总览不改变实际确认进度；预演和手动确认的引导记录分别标注。本机时间发生回拨时，到达页仍显示刚完成的正确路线。
- 搜索支持多个关键词、编号优先排序和回车选择；从路线规划进入搜索后会留在原规划流程。默认起点、语音偏好与编号显示设置会保存在本机。
- 全景新增加载/缓冲/失败状态和重试；标注方向时暂停并冻结时间和画面朝向，保存/关闭后按原状态恢复播放。已有标注支持回看，删除支持撤销。
- 收藏和路线写入失败时会明确提示；删除本机路线/记录前会确认。资料始终保存在设备端，此版没有账号、付费或云端同步。

### 二维地图与路线

- 在地图上点房间，或使用顶部搜索框输入编号/名称。
- 选择“设为起点”和“路线规划”，再选目的地。
- “预演路线”会按图纸轮廓生成示意路径，并逐点播报。路线距离使用图纸坐标，门口、走廊和楼层连通性尚未现场核验。
- 需要把实地走过的路线录入时，进入“标注路线”，在地图上依次点选节点；只有勾选已现场核对，才能保存为已核验路线。保存路线可在设置中导出 JSON，便于备份和复核。

### 360° 视频导航

- 打开“全景导航”，导入本地 360° 等距柱状视频（通常为 2:1），或填写可访问的 HTTPS 视频直链。
- 拖动画面环视路线，播放时可打开“标注方向”，在当前视频时间记录文字和朝向。
- 方向标注绑定到视频文件和路线选择；重新导入同一文件会恢复本机保存的标注。
- 方向标注是视频时间轴上的提示，不等同于 GPS、IMU 或实时室内定位。普通平面视频不会自动变成 360° 视频。

### 语音

网页预览使用浏览器语音合成；安卓包优先调用系统 Text-to-Speech。可以在设置中测试语音。没有中文语音引擎时，先在系统 TTS 设置里安装中文语音数据。

## 从源码构建

需要 Node.js 22、JDK 21、Android SDK（API 36）和 Gradle 8.x。

```powershell
cd mobile
npm ci
npm run build
npx cap sync android
cd android
./gradlew.bat assembleDebug
```

生成文件：`mobile/android/app/build/outputs/apk/debug/app-debug.apk`。

如果 Windows 上 Gradle 因临时目录或 Java 回环连接失败，可把 `java.io.tmpdir` 和 `jdk.net.unixdomain.tmpdir` 指向一个短路径，并设置 `java.net.preferIPv4Stack=true` 后重新运行 Gradle。项目本身不需要服务器密钥，也不会把网站的 `.env` 或固件 `secrets.h` 打进 APK。

## 数据与限制

`src/data/rooms.json` 是 FF-01 图纸轮廓数据，当前有 159 个可搜索空间。路线算法使用这些轮廓推导可避开房间的栅格路径；它不知道真实门口、走廊、楼梯、无障碍通道或当前封闭区域。因此界面和播报会使用“示意路线 / 预演”字样，不能把它当作已经测绘完成的高德级室内导航。

要进入下一阶段，需要补充：现场核对的门口与走廊节点、楼层/无障碍属性、真实校园 360° 视频，以及可用的室内定位来源（例如蓝牙信标、Wi-Fi RTT 或手机 IMU 校准）。
